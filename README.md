# Fabula Ultima — Assistente Visual de Level Up (`fu-level-up-wizard`)

Módulo para **Foundry VTT (v12/v13)** e sistema **Fabula Ultima (`projectfu`)** com interface 100% em **Português (PT-BR)**, oferecendo uma tela animada de celebração de nível e uma árvore radial interativa para distribuição de classes e poderes.

## Instalação via Manifest URL
No Foundry VTT, acesse **Módulos Complementares > Instalar Módulo** e cole a URL abaixo no campo **Manifest URL**:

```text
https://raw.githubusercontent.com/GabriellSilveira/fu-level-up-wizard/main/module.json
